What Acxelin TLS defends against

It protects traffic against an attacker who records it now to decrypt later, and against one who forces a weaker negotiation. Each row below is a behaviour its tests check.

ThreatDefence
Forced downgrade to classical key exchange or certificatesThe strict policy refuses classical clients.
Replay of a recorded sessionThe server does nothing on a replay.
A revoked clientThe edge follows the revocation list and refuses the client. An expired or damaged list refuses everyone, with the reason logged.
Slow or silent clients holding connectionsHandshake and idle timeouts, and a connection limit per route.
Guessing an enrolment tokenTokens are one-time with a secret part. Failures are audited in an owner-only log that never holds the secret.
Secrets in outputAuthority and key passphrases and token secrets never appear in command output, logs or files at rest.

The console

The console is for one person on one machine.

Local only
It listens on 127.0.0.1 and refuses requests whose host name is not a loopback name or whose origin is another site, so a web page you visit cannot reach it.
Launch links
Opening it uses a link that works once, kept in the address fragment so it never reaches a server or a log, and removed from the address bar and history on arrival. The session it starts uses no cookies.
Keys on request only
Issued private keys are written to files on this computer. A key reaches the browser only when you choose With key, never for a revoked certificate or an encrypted key, and every issue, renewal, revocation and download is recorded in an owner-only audit log. The authority's passphrase is held in memory and is never written anywhere.
Limits
After ten wrong attempts in a minute from one address it refuses further tries. Request logs record the method, path and status, never a query, header or body.

What is not covered

  • Whoever holds the authority's key can issue certificates. Keep a root offline and issue from an intermediate authority.
  • A revoked certificate works until the edge next fetches the revocation list.
  • The service behind the edge sees plain traffic.
  • Browsers trust only public certificate authorities, which do not issue ML-DSA certificates yet, so serving them means a classical fallback certificate.
  • Everything here was exercised on Linux with OpenSSL 3.5.9.
