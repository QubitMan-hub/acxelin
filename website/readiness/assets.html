What this list does not promise

  • A missing finding is not proof that cryptography is absent. Code that builds an algorithm's name at run time, or reads it from a file outside the scan, can be missed.
  • An algorithm named in configuration is offered, not necessarily used. Live endpoints and packet captures show what is actually negotiated.
  • Key material is never read or written out: a key is recorded by its algorithm, size, format and place.
